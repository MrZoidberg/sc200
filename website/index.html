Temperature-aware fan control for Dell SC200 enclosures. One daemon, multiple enclosures, and a clear view of cooling.

Built for your homelab

  • Temperature-based fan curves with hysteresis and configurable fallback speeds.
  • Interactive device discovery and setup, plus dry run before enabling control.
  • Prometheus metrics, a Grafana dashboard, and JSON health reporting.

Install sc200

Requires Linux amd64 or arm64, systemd, curl, GNU tar, sha256sum, and standard account-management tools. Download and review the installer, then run it as root:

curl -fsSLo install.sh https://sc200.merkulov.me/install.sh
less install.sh
sudo bash install.sh

The installer verifies release checksums and opens interactive setup. It downloads the latest GitHub release by default; use --version vX.Y.Z to select a release.

Check your cooling

Compatibility is based on firmware 12Pack.Slot0.101. Verify temperatures under sustained load. If the host, daemon, or serial connection fails, sc200 cannot enforce cooling. Disable old fan-control jobs before setup.
