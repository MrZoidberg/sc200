Dell SC200
fan control & monitoring.

Control enclosure fans from Linux using temperature curves. Manage multiple enclosures with one daemon, discover serial devices, and monitor cooling in Grafana.

Install sc200

curl -fsSL https://sc200.merkulov.me/install.sh | sudo bash

Linux amd64 or arm64 with systemd. Requires curl, GNU tar, sha256sum, and standard account-management tools.

Prometheus metrics. Grafana dashboard.

Track sensor temperatures, measured fan RPM, requested fan speeds, telemetry freshness, and fallback status per enclosure. Scrape /metrics on port 9700 and import the included dashboard.

Discover your enclosures

Interactive setup finds supported enclosures and writes their serial paths and sensor indices. To preview configuration for a known port, stop the daemon and run:

sudo sc200 discover --port /dev/ttyS0 --profile safe

Add --write to save new devices. Existing enclosure settings are preserved. Prefer stable /dev/serial/by-id/… paths when available.

Choose a starting profile

Safe
The default: a 20% minimum, a curve from 20% at 25°C to 100% at 45°C, and 100% fallback speed.
Quiet
A 10% minimum, a curve from 10% at 25°C to 20% at 45°C, and 15% fallback speed. Select with --profile quiet.

Both profiles request 100% at the 45°C critical threshold. Profiles generate editable YAML for new devices; tune the values and verify temperatures under sustained load.

Configuration

Edit /etc/sc200/config.yaml and restart the service to apply changes. Defaults below match the Safe profile; Quiet changes min_speed, safe_speed, and curve. In YAML, temperatures and percentages are numbers without unit suffixes; durations use strings such as 10s.
